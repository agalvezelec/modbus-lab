# Modbus Lab

A collection of Modbus communication experiments, practical implementations and testing tools across different hardware platforms and embedded systems.

The repository explores Modbus RTU and Modbus TCP using microcontrollers, development boards and Python-based tools.

## Hardware Platforms

- Arduino UNO
- STM32
- ESP32
- Raspberry Pi

## Communication Protocols

- Modbus RTU
- Modbus TCP

## Tools and Technologies

- Python
- PyModbus
- PySerial
- Arduino
- STM32CubeIDE
- Linux
- USB-to-RS485 interfaces

## Projects and Experiments

Each platform contains independent projects, firmware, client applications and documentation.

The goal is to explore Modbus communication, master/slave architectures, register operations, protocol analysis and hardware integration.

## Status

Experimental repository. Projects are developed and documented independently.
